

<h1>📊 Social Media Engagement & Sentiment Analysis using Hadoop</h1>

<div class="section">
<h2>🚀 Project Overview</h2>
<p>
This project demonstrates a complete <b>Big Data pipeline</b> using Hadoop ecosystem tools.
It analyzes social media data to identify <b>user sentiment</b> and <b>engagement patterns</b>.
</p>
</div>

<div class="section">
<h2>🎯 Objectives</h2>
<ul>
<li>Classify social media comments into positive and negative sentiment</li>
<li>Perform large-scale data processing using Hadoop</li>
<li>Understand MapReduce workflow</li>
<li>Analyze data using Hive queries</li>
</ul>
</div>

<div class="section">
<h2>🏗️ Architecture</h2>
<p><b>Data Flow:</b></p>
<p>Raw Dataset → HDFS → MapReduce → Processed Data → Hive → Insights</p>

</div>

<div class="section">
<h2>🔄 Data Flow Explanation</h2>
<ul>
<li>Dataset is stored in HDFS</li>
<li>Mapper processes input data</li>
<li>Reducer aggregates results</li>
<li>Output is stored in HDFS</li>
<li>Hive is used for analysis</li>
</ul>
</div>

<div class="section">
<h2>🛠️ Tools & Technologies</h2>
<ul>
<li>HDFS (Hadoop Distributed File System)</li>
<li>MapReduce (Hadoop Streaming)</li>
<li>Hive</li>
<li>Python</li>
<li>Linux Terminal</li>
</ul>
</div>

<div class="section">
<h2>📁 Dataset Description</h2>
<p>The dataset contains social media data including engagement metrics and user comments.</p>

<table>
<tr><th>Column</th><th>Description</th></tr>
<tr><td>id</td><td>Unique Post ID</td></tr>
<tr><td>user</td><td>User Name</td></tr>
<tr><td>platform</td><td>Social Media Platform</td></tr>
<tr><td>post_type</td><td>Type of Post</td></tr>
<tr><td>likes</td><td>Number of Likes</td></tr>
<tr><td>shares</td><td>Number of Shares</td></tr>
<tr><td>comments</td><td>Number of Comments</td></tr>
<tr><td>comment_text</td><td>User Comment</td></tr>
</table>
</div>

<div class="section">
<h2>⚙️ Implementation Steps</h2>
<ol>
<li>Create dataset (CSV file)</li>
<li>Upload dataset to HDFS</li>
<li>Create Mapper and Reducer</li>
<li>Perform local testing</li>
<li>Run Hadoop job</li>
<li>Store output in HDFS</li>
<li>Analyze using Hive</li>
</ol>
</div>
